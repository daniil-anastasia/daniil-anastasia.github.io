# Куда класть фотографии

Положите сюда реальные снимки и пропишите пути в `js/config.js`.

Рекомендации:

| Что | Формат | Длинная сторона | Вес |
|---|---|---|---|
| Детские (первый экран) | WebP или JPEG, кроп 1:1 | 1000–1200 px | до 150 КБ |
| Галерея (~12 шт.) | WebP (AVIF ещё лучше) | 1400–1800 px | до 250 КБ |
| Финальный кадр | WebP, горизонтальный | 2000 px | до 350 КБ |

Пример записи в конфиге:

```js
{
  src: 'assets/photos/g-01.webp',
  alt: 'Даниил и Анастасия на набережной',
  w: 1400, h: 1750,
  sources: {                       // необязательно, но ускоряет загрузку
    avif: 'assets/photos/g-01.avif',
    webp: 'assets/photos/g-01.webp'
  }
}
```

`w` и `h` — реальные пиксели исходника. Они нужны, чтобы страница
не «прыгала» во время загрузки.

Быстрая конвертация (ImageMagick):

```
magick input.jpg -resize 1600x1600> -quality 82 assets/photos/g-01.webp
```
